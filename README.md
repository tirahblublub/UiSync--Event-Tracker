# UiSync - Event Tracker System

## Description
UiSync is a modern, web-based Event Tracker System designed to streamline the management of upcoming events, track guest speakers, and monitor participant registrations. Tailored for dynamic event environments, the platform provides real-time client-side interactivity, structured content presentation, and data insights to enhance organizational workflows. 

This project is developed as part of the **IMS566: Advanced Web Design Development & Content Management** course.

---

## Features Included
*   **Dynamic Analytics Dashboard:** Visualizes key metrics, statistics, and participant distributions.
*   **Speaker & Event Schedule Tracker:** Interactively displays event timelines, slotting specific guest speakers (e.g., international developers and designers) into daily sessions.
*   **Interactive Participant Management:** Fully functional client-side management allowing users to search, filter, add, and update participant records directly through an interactive table interface.
*   **Responsive Sidebar Navigation:** Smooth, centralized layout built for scannable navigation across desktop and mobile views.

## Instructions to Test Localhost Execution

Since this system utilizes PHP structures to seamlessly align with server-side web standards, follow these instructions to host and test the application on your local machine:

### Prerequisites
1. Ensure you have **XAMPP** (or WampServer) installed on your computer.
2. Download the project repository files as a ZIP archive and extract them.

### Step-by-Step Setup
1. **Move Project Folder:** Copy the extracted project folder (named `event`) and paste it into your local XAMPP root directory:
   * **Path:** `C:\xampp\htdocs\event\`
2. **Launch XAMPP Control Panel:** Open the XAMPP Control Panel application.
3. **Start Apache Server:** Click the **Start** button next to the **Apache** module. Ensure the module label turns green, indicating the local server is successfully running.
4. **Access via Browser:** Open Google Chrome or any modern web browser and enter the following local URL:
   * 👉 `http://localhost/events/index.php` (or simply `http://localhost/events/`)

## Frameworks & Libraries Used
The project is built using a clean mix of structured front-end styling frameworks alongside core back-end scripting files to deliver a high-fidelity user interface:

*   **HTML5 & CSS3:** For semantic structure, modern background gradients, and high-end glassmorphism layouts.
*   **PHP:** Utilized for structural file routing configurations and standardizing repository architecture.
*   **JavaScript (ES6):** Powers all application logic including instant search parameters, array processing, form handling, and modal triggers.
*   **Bootstrap v5.3.3:** Provides responsive layout systems, navigation components, custom interactive modals, and pre-styled table typography.
*   **Bootstrap Icons v1.11.3:** For clean, scalable iconography used throughout the sidebar menu and status badges.
